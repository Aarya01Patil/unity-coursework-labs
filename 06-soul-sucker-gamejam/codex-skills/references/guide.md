# Fast jam playtest rubric

Use this when the user wants a quick pass instead of a full review.

## Immediate checks

Ask or evaluate:
- Can the player describe the goal in 10 seconds?
- Do they understand the main input in 30 seconds?
- Do they hit the interesting mechanic in the first minute?
- After a failure, do they want one more try?

## Cut triggers

Recommend a cut when:
- a feature is not required for the core loop
- a system adds explanation cost without adding fun
- the player can finish the game without understanding why it exists
- it is causing bugs, tuning time, or room design overhead

## Polish triggers

Recommend polish only when the build is already complete enough to ship.
Focus on readability, feedback, and restart speed before visual extras.
